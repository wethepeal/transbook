transbook —— 电子书翻译流水线（Windows 开箱即用包）
=====================================================

这个压缩包里有两个东西：

    start.cmd                      ← 双击它就行
    transbook-<版本>-py3-none-any.whl   ← 程序本体（Web 界面已内嵌）

注意：程序本体只有 200 多 KB，但它依赖的组件（含 PDF 排版引擎 Typst）会在
首次运行时联网下载，**装完大约占用 150 MB 磁盘**。请留出空间并保持网络通畅。


一、怎么用（三步）
------------------

1. 把整个压缩包解压到一个**有写权限的普通文件夹**（比如 D:\transbook）。
   不要放在 C:\Program Files 下。

2. 双击 start.cmd。

3. 首次运行会依次做这几件事，跟着屏幕提示走即可：
   · 自动下载安装 uv（Python 的包管理器，装在你自己用户目录下，不需要管理员）
   · 安装 transbook 本体及其依赖（约 150 MB，需要联网，视网速几分钟）
   · 用中文提示你粘贴一次 DeepSeek API Key（申请地址 https://platform.deepseek.com/api_keys ）
   · 启动本地服务，并自动打开浏览器 http://127.0.0.1:8321/

   **那个黑窗口就是服务本体，别关它。** 关掉窗口 = 停止服务。


二、界面里怎么用
----------------

1. 首页点「上传」，选一个 EPUB 或 PDF（英文或日文都行）。
2. 选引擎（默认 DeepSeek），点「上传并开始翻译」。
3. 看着进度条跑完。一本 40 万字的书，实测约 12 分钟、花费约 0.8 元。
4. 想逐段核对就点「校对」进去改；不想改就直接在详情页下载成品。
5. 成品有两种，都在详情页的「产物」里：
   · 双语版（原文 + 译文对照）—— 适合学习、核对
   · 纯中文版 —— 适合直接阅读
   每种都可以出 EPUB 和 PDF。


三、改 API Key / 换模型
-----------------------

首次运行后，start.cmd 同目录下会有一个 .env 文件，用记事本打开即可改：

    DEEPSEEK_API_KEY=sk-你的密钥
    DEEPSEEK_BASE_URL=            （留空用官方地址；填本地地址即可用本地模型）
    TRANSLATE_MODEL=deepseek-flash

改完保存，重新双击 start.cmd 生效。
密钥只存在这个文件里，不会上传、也不会进代码仓库。


四、升级
--------

下载新的压缩包，解压覆盖（或者解压到新目录），双击新的 start.cmd 即可，
start.cmd 会自动覆盖安装成新版。旧版的书籍数据在 work 目录里，不受影响。


五、卸载
--------

1. 删除你解压出来的那个文件夹（连同里面的 work 子目录，即所有翻译成果）。
2. 删除 C:\Users\你的用户名\.local\bin\tp.exe
3. 如果连 uv 也不想要了，删除 C:\Users\你的用户名\.local\bin\uv.exe
   以及 C:\Users\你的用户名\.local\share\uv


六、出问题了怎么办
------------------

· 双击后窗口一闪就没了
  右键 start.cmd → 「编辑」看不到的话，用命令提示符运行它，就能看到报错内容。

· 提示"没找到 .whl 文件"
  start.cmd 必须和 transbook-*.whl 放在同一个文件夹里。

· 提示 uv 安装失败
  网络问题。可以手动装：https://docs.astral.sh/uv/getting-started/installation/
  装完再双击 start.cmd。

· 浏览器打开是空白 / 提示前端未构建
  说明装的包不完整。请用这个官方压缩包里的 .whl，不要自己从源码打包。

· 杀毒软件报警
  本程序不联网做任何事，除了调用你自己配置的 DeepSeek API。
  所有代码都在 GitHub 仓库里公开可查。

· 端口 8321 被占用
  用命令提示符执行：tp serve --root work --port 8322 --open


七、它到底做了什么（给不放心的用户）
------------------------------------

流水线共五个阶段，每个阶段都有独立的中间产物，可以随时中断续跑：

    ① 抽取   PDF/EPUB → 统一的中间表示（IR）
    ② 入库   建翻译记忆库，重复段落不重复付费
    ③ 翻译   调 DeepSeek 逐段翻译
    ④ 校对   AI 质检 + 人工逐段修改
    ⑤ 渲染   IR → 双语/纯中文的 EPUB + PDF

原文和处理结果全部留在你自己的电脑上，只有"要翻译的段落文本"会发到
你配置的翻译接口。
